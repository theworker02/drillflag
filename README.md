# drillflag

Drill CSV/TSV flag tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/drillflag/

## Install / run

```bash
git clone https://github.com/theworker02/drillflag.git
cd drillflag
node src/cli.js
node --test
```
